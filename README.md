## 🚀 How to Host on GitHub Pages (Free in 2 Minutes)

Follow these simple steps to deploy your website live on the internet:

### Step 1: Create a Repository on GitHub
1. Log in to your [GitHub](https://github.com/) account.
2. Click the **`+`** icon in the top right corner and choose **New repository**.
3. Set your repository name (for example, `babashiv-cafe`).
4. Select **Public**.
5. Click **Create repository**.

### Step 2: Upload Files
1. Inside your new repository, click **Add file** ➔ **Create new file**.
2. Name the file: `index.html`
3. Paste the entire `index.html` code and click **Commit changes**.
4. Repeat the process: click **Add file** ➔ **Create new file**, name it `README.md`, paste this README content, and commit.

### Step 3: Enable GitHub Pages
1. Go to **Settings** (gear icon) in your repository menu.
2. In the left sidebar, click **Pages**.
3. Under **Build and deployment**:
   - **Source:** Choose `Deploy from a branch`.
   - **Branch:** Select `main` (or `master`) and directory `/ (root)`.
4. Click **Save**.

### Step 4: Your Website is Live!
- Wait 60 to 90 seconds, then refresh the **Pages** settings screen.
- You will receive your public URL:
  `https://<your-username>.github.io/<repository-name>/`
